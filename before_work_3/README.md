# Early Exploratory Work (before_work_2/ and before_work_3/)

## Purpose

These directories contain initial exploratory scripts and experiments from the early stages of the project. Code here represents learning phase and method development.

## Contents

### Common Scripts
- **`lammpin.py`**: Early LAMMPS input file generator
- **`pdf.py`**: Initial PDF calculation attempts
- **`runner.py`**: Basic batch processing
- **`probe.py`**: Probe/test calculations
- **`randomremoval.py`**: Random atom removal experiments
- **`change_prob.py`**: Probabilistic element assignment
- **`change_eti.py`**: Element label changes
- **`rdf_runner.py`**: RDF calculation automation (in before_work_3)
- **`contar_p.py`**: Atom counting utility (in before_work_3)
