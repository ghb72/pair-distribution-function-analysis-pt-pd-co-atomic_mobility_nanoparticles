# Paper Notes and Corrections (paper/)

## Purpose

This directory contains notes, corrections, and supplementary materials related to the scientific paper/publication derived from this thesis work.

## Typical Contents

- **Draft revisions**: Manuscript versions
- **Reviewer responses**: Corrections and clarifications
- **Supplementary materials**: Additional figures and data
- **Calculation notes**: Details for methods section
- **Figure sources**: High-resolution versions for publication

## Organization

Files may be organized by:
- Submission/revision rounds
- Manuscript sections
- Reviewer comments
- Supplementary information

## Related Directories

Data supporting the paper comes from:
- `notebooks/`: Analysis and visualizations
- `results/`: Generated figures and data
- Date-stamped directories: Original calculations

## Note

This directory is specific to publication workflow and may contain:
- Copyright-restricted materials
- Unpublished data
- Internal review comments

See main thesis documentation and `README.md` for public-facing content.
