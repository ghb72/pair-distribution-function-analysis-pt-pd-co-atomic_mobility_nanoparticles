# Example Files and Reference Materials (examples/)

## Purpose

This directory contains reference examples, sample input files, and templates for reproducibility and teaching purposes.

## Contents

Typical contents may include:
- **Sample XYZ files**: Example atomic coordinates
- **LAMMPS templates**: Reference input files
- **Configuration examples**: Parameter file samples
- **Test cases**: Small systems for validation
- **Tutorial materials**: Step-by-step examples

## Usage

Files here serve as:
1. **Starting points** for new simulations
2. **Test cases** for validating installations
3. **Templates** for creating new input files
4. **Documentation** of file formats

## Running Examples

```bash
# Copy example to working directory
cp examples/<example_file> ./

# Modify for your specific system
# Run analysis or simulation
```

## Validation

Examples should produce known, reproducible results. Use them to:
- Test LAMMPS installation
- Validate RDF/PDF calculations
- Check visualization tools
- Understand file formats
